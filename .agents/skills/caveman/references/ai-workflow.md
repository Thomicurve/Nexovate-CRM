# AI-Workflow V3 — optional internal style

Caveman lite is optional on explicit request. Normal internal handoffs already use concise
complete sentences; no mandatory skill/reference loading for routine work.
Routing and authority are defined in .codex/workflow/docs/request-routing.md and selected role contracts.
Style never changes approvals, scope, IDs, conditions, evidence, exact commands or uncertainty.
User messages and persisted documents stay clear normal prose.
Small/standalone Delivery handoffs omit irrelevant empty fields. Tracked handoffs keep
governing criteria/checks/results, not repeated templates or conversation.
No new stage/report/context files, generated images/captures/exports or provider operations.
No stage chain, memory mirror, review or task continuation ceremony from a style request.
Existing feature policies remain until explicit migration; style grants no authority.
